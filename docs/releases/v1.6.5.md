## 007 Remastered 1.6.5: portable launcher

- **Portable by default.** New installs keep the launcher's data in `.launcher/` beside the launcher, next to
  `NightFire/` and `AgentUnderFire/`, instead of AppData. The whole folder can be moved or copied to another PC.
- **Existing installs can switch.** Settings now has a **Portable mode → Make portable** button. It moves the
  launcher's profile beside the launcher and restarts.
- **Relative game paths.** Each game's `launcher.json` now stores the disc image path relative to its game folder;
  old absolute paths still work.

Downloads: Windows launcher (.exe, both games), Linux launcher (.AppImage), macOS launcher (.dmg) and the Android app (.apk).

No game files are included: the launcher builds the games from your own Xbox disc.
