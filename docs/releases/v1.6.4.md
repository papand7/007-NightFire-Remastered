## 007 Remastered 1.6.4: Vulkan fixes, macOS presentation, Mali, CMake 4 and cheats

- **macOS: the game now shows a picture.** The Vulkan surface is made again after the window is shown and after display changes, and out-of-date or lost swap chains recover. This fixes the black window (with only the pointer) on Apple Silicon and the same no-image report.
- **Vulkan startup is clearer.** The renderer logs each init stage, lists every usable GPU with its Vulkan version, driver and memory, prefers the strongest GPU, and falls back to another one if device creation fails. This fixes the RTX A400/5080 case and gives a useful log for any remaining failure.
- **Android on Mali works.** No `SV_ClipDistance` is written on GPUs without it, DXT textures are decoded to BGRA when BC formats are absent, the blood-stain timestamp no longer writes past the query pool, and a lost device reports its `VK_EXT_device_fault` details.
- **CMake 4 builds work.** Vulkan-Headers' C++ module is disabled, DXC's Android build is patched for CMake 4, and a second Build click no longer reports “Busy with build.”
- **The macOS launcher keeps your ISO.** It remembers the copy in `play/assets` and falls back to it when the original path (for example an iCloud file) is unavailable.
- **Cheats tab for both games.** Turn on **God mode** and **Infinite ammo** from the launcher for NightFire and Agent Under Fire. These are single-player cheats and can affect saves, achievements and multiplayer.

Downloads: Windows launcher (.exe, both games), Linux launcher (.AppImage), macOS launcher (.dmg) and the Android app (.apk).

No game files are included: the launcher builds the games from your own Xbox disc.
